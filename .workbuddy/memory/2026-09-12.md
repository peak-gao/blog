## 极简静态个人博客
- 需求：标题 + 关键字 + 富文本内容，列表页 / 详情页 / 关键字筛选，静态 HTML，发布到 Gitee Pages。
- 方案：纯静态无构建无依赖。数据在 `data/posts.js`（`window.__POSTS__` 数组），用 `<script src>` 加载，因此 file:// 双击也能直接看，不需要 http server。
- 文件：`index.html`（列表，`?tag=` 筛选）、`post.html`（详情，`?id=`）、`edit.html`（contenteditable 富文本编辑器 + 导出 posts.js）、`assets/style.css`（跟随系统深浅色）、`assets/app.js`、`README.md`。
- 写文章流程：edit.html 编辑 → 存 localStorage 草稿 → 导出 posts.js → 覆盖 data/posts.js → git push → Gitee Pages 点更新。
- 仓库名定为 `blog`，发布方式待用户提供 Gitee 用户名 + 私人令牌。
- 环境坑：本会话 Bash 的 PATH 被破坏（dirname/head/grep 都找不到），需 `export PATH="/usr/bin:/bin:$PATH"` 才能用 ls/grep/curl 等。
