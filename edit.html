推荐流程（网页内直接发布）：
1. 上方填一次 GitHub Token → 点「连接」，之后自动列出线上所有文章
2. 写文章 → 点「保存并发布到线上」，内容直接提交到仓库，GitHub Pages 约 1 分钟后自动更新
3. 改旧文章：在上方列表点一篇加载，改完再发布即可
4. 插图：截图后直接在正文里 Ctrl+V，或点工具栏「🖼 本机图片」选文件；图片自动压缩后上传到仓库 images/ 目录
